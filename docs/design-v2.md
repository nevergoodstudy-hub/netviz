# Wireshark PCAP 数据包可视化分析平台 - 第二版可行性设计方案

## 一、项目定位升级

### 1.1 从工具到平台
第一版定位为"可视化工具"，第二版升级为**网络流量智能分析平台**，集成：
- 深度数据包检测(DPI)
- 安全威胁情报
- 机器学习异常检测
- 协作取证分析
- AI智能分析助手

### 1.2 目标用户群
- 网络安全分析师 (SOC Analyst)
- 数字取证调查员
- 红队/蓝队测试人员
- 网络运维工程师
- 安全研究人员
- 个人安全爱好者

## 二、系统架构设计

### 2.1 六层架构
```
┌────────────────────────────────────────────────────────────────┐
│                    展示层 (Presentation Layer)                  │
│  React/Vue + D3.js + ECharts + Leaflet + Three.js             │
├────────────────────────────────────────────────────────────────┤
│                    API网关层 (API Gateway)                      │
│  Kong/Nginx + GraphQL + REST API + WebSocket                   │
├────────────────────────────────────────────────────────────────┤
│                   业务逻辑层 (Business Logic)                   │
│  协议解析 | 会话重组 | 威胁检测 | 异常分析 | 报告生成           │
├────────────────────────────────────────────────────────────────┤
│                   智能分析层 (Intelligence Layer)               │
│  ML异常检测 | 威胁情报关联 | MITRE ATT&CK映射 | AI分析助手      │
├────────────────────────────────────────────────────────────────┤
│                   数据处理层 (Data Processing)                  │
│  Scapy/PyShark | Apache Kafka | Spark Streaming | Celery       │
├────────────────────────────────────────────────────────────────┤
│                   存储层 (Storage Layer)                        │
│  Elasticsearch | Neo4j | PostgreSQL | Redis | MinIO(PCAP存储)  │
└────────────────────────────────────────────────────────────────┘
```

### 2.2 数据流架构
```
PCAP文件 ──→ 解析队列 ──→ 特征提取 ──→ 实时分析 ──→ 可视化
    │                         │              │
    └──→ 原始存储(MinIO)     └──→ 索引(ES)  └──→ 告警(WebSocket)
```

## 三、核心功能模块 (增强版)

### 3.1 深度协议分析引擎

#### 3.1.1 多层协议解析
| 层级 | 支持协议 |
|------|----------|
| 链路层 | Ethernet, 802.11 WiFi, VLAN, ARP |
| 网络层 | IPv4, IPv6, ICMP, IPSec |
| 传输层 | TCP, UDP, SCTP, QUIC |
| 应用层 | HTTP/2/3, DNS, TLS/SSL, SMTP, FTP, SSH, RDP, SMB, LDAP |
| 工控协议 | Modbus, DNP3, S7comm, OPC-UA |

#### 3.1.2 会话重组与内容提取
- **TCP流重组**: 完整还原TCP会话
- **文件雕刻(File Carving)**: 从流量中提取传输的文件(图片、文档、压缩包)
- **凭据提取**: HTTP Basic Auth, NTLM哈希, Kerberos票据
- **TLS会话分析**: 证书链解析、加密套件识别、自签名/过期证书检测

### 3.2 多维可视化系统

#### 3.2.1 网络拓扑视图
- **力导向图**: 节点代表主机，边代表通信关系
- **分层视图**: 按网络层级(外网/DMZ/内网)分层展示
- **时间切片**: 可按时间段动态演示网络结构变化
- **节点聚类**: 自动识别服务器、客户端、路由器等角色

#### 3.2.2 地理位置可视化
- 集成MaxMind GeoIP2数据库
- 支持离线数据库和在线API两种模式
- **可视化形式**:
  - 全球热力图显示流量分布
  - 连接线动画展示跨地域通信
  - 国家/城市级别下钻分析

#### 3.2.3 时序分析视图
- **时间线**: 精确到微秒的事件时间轴
- **流量曲线**: 带宽使用、包速率实时曲线
- **协议分布堆叠图**: 各协议占比随时间变化
- **会话甘特图**: 多会话并行时序展示

#### 3.2.4 协议层次视图  
- **桑基图(Sankey)**: 协议栈层级流转关系
- **树状图(Treemap)**: 协议占比分布
- **环形饼图**: 多层协议嵌套关系

#### 3.2.5 统计仪表盘
- Top-N 通信对、端口、协议排行
- 异常指标实时监控面板
- 自定义KPI指标卡

### 3.3 智能威胁检测系统

#### 3.3.1 基于机器学习的异常检测
**检测方法**:
- 无监督方法：聚类、基于密度的算法、降维技术
- 有监督方法：分类算法、集成模型、深度学习模型

**算法选型**:
| 算法 | 准确率 | 适用场景 |
|------|--------|----------|
| XGBoost | 99% | 高精度检测 |
| Random Forest | 94.3% | 复杂网络流量 |
| SVM | 96.5% | 异常分离 |
| Isolation Forest | - | 无监督异常检测 |
| Autoencoder | - | 深度学习异常检测 |

**检测能力**:
- 东西向流量横向移动检测
- 协议异常和滥用识别
- 数据流模式异常检测
- DDoS攻击检测
- 端口扫描识别
- C2通信检测
- 数据外泄告警

#### 3.3.2 MITRE ATT&CK 框架集成
- 自动映射检测到的行为到ATT&CK技术
- 生成ATT&CK Navigator热力图
- 关联已知APT组织TTP

#### 3.3.3 威胁情报关联
- 集成开源威胁情报源(MISP, OTX, VirusTotal)
- IP/域名信誉查询
- IoC(失陷指标)自动匹配
- 恶意文件哈希比对

### 3.4 AI智能分析助手

#### 3.4.1 核心能力
- 自然语言查询：用自然语言描述想要查找的流量特征
- 智能摘要：自动生成PCAP文件分析摘要
- 异常解释：对检测到的异常提供详细解释
- 安全建议：根据分析结果提供安全改进建议
- 攻击溯源：辅助分析攻击链路

#### 3.4.2 支持的AI提供商
- OpenAI (GPT-4/GPT-4o)
- Anthropic (Claude)
- 本地模型 (Ollama/LM Studio)
- Azure OpenAI
- 其他兼容OpenAI API的服务

#### 3.4.3 使用场景
- "查找所有可疑的DNS请求"
- "分析这个IP地址的所有通信行为"
- "解释为什么这个会话被标记为异常"
- "生成本次抓包的安全分析报告"

### 3.5 数字取证模块

#### 3.5.1 证据链管理
- 完整性校验(哈希链)
- 时间戳认证
- 操作审计日志

#### 3.5.2 时间线重建
- 事件时间线自动生成
- 多源事件关联
- 攻击路径可视化

#### 3.5.3 报告生成
- 符合法律取证要求的报告模板
- 多格式导出(PDF/HTML/Word)
- 证据截图自动标注

## 五、性能优化策略

### 5.1 大文件处理
- **分片上传**: 前端文件分片，支持断点续传
- **流式解析**: 不将整个PCAP载入内存
- **增量索引**: 边解析边建立索引
- **采样分析**: 超大文件支持智能采样

### 5.2 查询优化
- **预计算聚合**: 定时任务预计算统计指标
- **布隆过滤器**: 快速判断IP/域名是否存在
- **缓存策略**: 多级缓存热点数据

### 5.3 可视化性能
- **WebGL渲染**: 大规模节点使用Canvas/WebGL
- **虚拟滚动**: 长列表虚拟化
- **懒加载**: 按需加载可视化组件
- **数据降采样**: 时序图动态降采样

# NetViz Repository

This repository hosts the active NetViz application in [`netviz/`](netviz), including:

- a React + TypeScript frontend
- a FastAPI analysis backend
- a Tauri desktop shell with a bundled backend sidecar

Start with the project README at [`netviz/README.md`](netviz/README.md).
